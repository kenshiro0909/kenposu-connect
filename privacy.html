プライバシーポリシー Privacy Policy

Last updated: October 23, 2026

1. 取得する情報 / Information we access

利用者が自分で連携したアカウントについて、投稿に必要な最小限の情報（アカウントID、表示名、アイコン、アクセストークン、投稿の数値）だけを取得します。TikTokでは、open_id・表示名・アイコン（user.info.basic）と、投稿のための権限（video.publish / video.upload）を使います。

For accounts the user connects, we access only what is needed to post: account ID, display name, avatar, access tokens and post metrics. For TikTok we use open_id, display name and avatar (user.info.basic) and posting permissions (video.publish / video.upload).

2. 使い方 / How we use it

利用者が予約した投稿を、指定した日時に利用者本人のアカウントへ公開するため、また利用者本人が投稿の結果を確認するためだけに使います。広告・販売・第三者への提供はしません。

Only to publish the user's own scheduled posts to the user's own accounts and to show the user the results. We never sell data, use it for ads, or share it with third parties.

3. 保存場所 / Storage

情報は利用者本人のGoogleアカウント内（Google Apps Scriptとスプレッドシート）にだけ保存され、運営者のサーバーには保存しません。

Data is stored only inside the user's own Google account (Google Apps Script properties and a spreadsheet), not on our servers.

4. 削除 / Deletion

管理画面の「連携」で「外す」を押すと、保存したトークンはすぐに削除されます。各SNSの設定から連携を取り消すこともできます。

Clicking "Disconnect" in the dashboard deletes stored tokens immediately. Users can also revoke access from each platform's settings.

5. お問い合わせ / Contact

お問い合わせ：このサービスの運営者まで（連絡先は準備中）

Contact: the operator of this service.
